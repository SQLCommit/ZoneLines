ZoneLines - Optional label fonts

1. Right-click a bundled .ttf file and choose Install in Windows.
2. Fully close and restart FFXI. An addon reload is not enough.
3. Open /zl and choose Labels > Fonts > Font.

For a custom font, first put its .ttf or .otf file in this folder,
then follow the same steps. ZoneLines does not install fonts for you.

Bundled options: Grammara, Mystic Gate, and Oswald.
Common Windows fonts in the picker need no extra installation.

See ../FONTS.md for the full instructions.
